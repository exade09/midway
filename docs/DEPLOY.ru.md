# Запуск Midway на Vercel

## 1. Что понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Helius API key | скан кошельков, проверка сжиганий, история свапов для оценки потерь | helius.dev → бесплатный тариф |
| Отдельный кошелёк банка | получает долю ренты с каждого сжигания и платит победителю | новый кошелёк, только под Midway |
| Neon (Postgres) | квитанции, кладбище, розыгрыши | Vercel → Storage → Neon |
| Anthropic API key (необязательно) | Зазывала пишет реплики сам, а не по шаблонам | console.anthropic.com |

## 2. GitHub → Vercel

1. Создать пустой репозиторий на GitHub (без README).
2. В папке проекта:
   ```bash
   git remote add origin https://github.com/<вы>/midway.git
   git push -u origin main
   ```
   Если пришёл `midway.bundle`: `git clone midway.bundle midway && cd midway`, затем команды выше.
3. Vercel → Add New → Project → импортировать репозиторий. Настройки сборки не трогать.
4. Vercel → Storage → Create → Neon → подключить к проекту (`DATABASE_URL` появится сам).
5. Заполнить переменные (ниже) и нажать Redeploy.
6. Открыть `https://<домен>/api/health` — все обязательные пункты должны быть `true`.

На GitHub при каждом пуше запускается проверка (`.github/workflows/ci.yml`): линт, типы, тесты, сборка.

## 3. Переменные окружения (Vercel → Settings → Environment Variables)

```
HELIUS_API_KEY=...
NEXT_PUBLIC_POT_WALLET=<адрес кошелька банка>
NEXT_PUBLIC_POT_CUT_BPS=500          # 5% от возвращённой ренты
NEXT_PUBLIC_DRAW_HOUR_UTC=18         # 21:00 МСК
CRON_SECRET=<любая длинная случайная строка>
DATABASE_URL=<ставится сам при подключении Neon>
NEXT_PUBLIC_SITE_URL=https://<ваш домен>
NEXT_PUBLIC_TOKEN_CA=                # пусто → в шапке «soon»; после запуска токена — CA
ANTHROPIC_API_KEY=                   # по желанию
DRAW_PAYOUT_SECRET=                  # по желанию, см. ниже
```

`NEXT_PUBLIC_*` вшиваются в сайт при сборке — после изменения нужен редеплой.

## 4. Выплаты

- **Вручную (по умолчанию).** Оставьте `DRAW_PAYOUT_SECRET` пустым. Каждый вечер крон выбирает победителя, он виден на сайте и в `/api/draw/proof`. Вы переводите банк сами.
- **Автоматически.** Положите в `DRAW_PAYOUT_SECRET` секретный ключ кошелька банка массивом байт (`[12,34,...]`). Держите в этом кошельке только банк.

## 5. Крон

`vercel.json` уже содержит два запуска: 18:03 и 18:20 UTC (второй — страховка, повторный запуск ничего не ломает). На бесплатном тарифе Vercel может запустить крон в любую минуту этого часа — это нормально: блок для seed задаётся сетью, а не временем запуска. Если меняете час розыгрыша — поменяйте и час в `vercel.json`.

## 6. Проверка после деплоя

1. `/api/health` → `"ok": true`.
2. Открыть сайт → «Walk the demo lot» → пройти весь сценарий.
3. Подключить свой кошелёк, похоронить 1–2 пустых аккаунта. Проверить, что квитанция появилась, рента вернулась, в банк пришла доля.
4. Открыть `/api/draw` — должен показать банк и ваши билеты (если хоронили настоящий токен).
5. Нажать CA в шапке — адрес копируется.
6. `/docs` открывается, оглавление подсвечивает главы.

## 7. Перед запуском

Ежедневный розыгрыш с призом, где участие зависит от действий пользователя, в части стран регулируется как лотерея/промо-акция. Проверьте, что применимо к вашей аудитории, до продвижения.
